# 🚀 Desafio Frontend - Accenture

## 📋 Sobre o Projeto

Projeto de automação de testes para o site [DemoQA](https://demoqa.com) com:

- ✅ Testes de API com Python (URLLib)
- ✅ Testes de API com Postman
- ✅ Testes E2E com Cypress
- ✅ Testes BDD com Cucumber
- ✅ Page Objects

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Versão | Finalidade |
|------------|--------|------------|
| Python | 3.8+ | Testes de API |
| URLLib | built-in | Requisições HTTP |
| Postman | latest | Testes de API |
| Cypress | 13.x | Testes E2E |
| Cucumber | 24.x | BDD |
| Node.js | 18+ | Runtime |

## 📦 Instalação

### 1. Clonar o Projeto
```bash
git clone https://github.com/zeth-I/Accenture-DemoQA
``` 
### 2. Para instalar as dependências
```bash
npm install
```
### 3. Instalar o Cypress
```bash
npx cypress install
```
### 3. Executar o Cypress
```bash
npx cypress open
```
